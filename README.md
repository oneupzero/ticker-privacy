# 티커 개인정보처리방침

관망 스튜디오의 티커(com.ticker.game) 개인정보처리방침을 제공하는 정적 페이지입니다.

- `index.html`: 전체 정책 본문과 GitHub Pages 호스팅 안내
- `.nojekyll`: HTML을 그대로 게시하기 위한 설정
- 문의: qlqjs316@gmail.com

GitHub Pages 게시 소스는 `main` 브랜치의 `/(root)`입니다. 로그인 없이 열리는 HTTPS 페이지를 Google Play 개인정보처리방침 URL로 사용합니다.

정책 내용 원본은 게임 프로젝트의 `src/ui/content/privacyPolicy.json`입니다. 게임 프로젝트에서 `node scripts/export-privacy-pages.mjs`를 실행한 뒤 이 폴더의 게시용 파일을 정책 저장소에 반영합니다. 정책 본문을 이 저장소에서만 별도로 수정하지 않습니다.
