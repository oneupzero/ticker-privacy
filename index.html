1. 개인정보 수집과 이용

티커는 회원가입이나 로그인을 제공하지 않으며, 앱에서 이름, 이메일 주소, 전화번호, 실제 금융정보를 입력받지 않습니다. 게임 이용 중 개인정보나 플레이 데이터를 개발자 서버로 수집하거나 전송하지 않습니다.

광고, 사용자 추적, 외부 이용 분석 및 오류 수집 서비스를 사용하지 않습니다. 게임 속 종목, 자산, 대출과 거래는 모두 가상의 게임 데이터입니다. 이용자가 직접 보내는 문의 이메일은 아래 ‘문의 처리’ 항목에 따라 처리합니다.

2. 기기에 저장하는 데이터와 목적

게임 결과와 기록 표시를 위해 모드, 플레이 시작·종료 시각과 진행 시간, 가상 자산·포트폴리오·거래·대출·상환 요약, 완주·파산 결과를 이용자의 기기에 저장합니다.

기록과 편의 기능을 위해 최근 기록, 모드별 최고 기록, 누적 통계, 업적, 소리·진동·화면 설정, 튜토리얼 완료 여부, 진행 중인 판의 중단 확인 표시와 저장 형식·앱 버전 정보를 기기에 저장합니다. 이 데이터는 개발자 서버에 저장되거나 다른 기기와 동기화되지 않습니다.

3. 외부 전송과 제3자 제공

티커 앱은 위의 로컬 게임 데이터를 제3자에게 제공하거나 판매하지 않으며, 외부 서버에 맡겨 처리하지 않습니다. 현재 게임에 사용하는 음악, 효과음, 이미지와 폰트는 앱에 포함된 파일을 사용합니다.

Google Play 등 배포 플랫폼과 기기 운영체제가 자체 서비스 제공을 위해 처리하는 정보에는 해당 서비스 제공자의 개인정보처리방침이 적용됩니다. 이는 티커가 개발자 서버로 플레이 데이터를 전송하는 기능과 별개입니다.

4. 데이터 보관과 삭제

최근 플레이 기록은 완주·최종 파산 결과를 합쳐 최대 50판, 최고 기록은 모드별 최대 10건을 기기에 보관합니다. 두 목록은 별도로 관리하므로 최근 목록에서 제외된 판도 최고 기록에 남을 수 있으며, 누적 통계와 업적은 계속 유지될 수 있습니다.

메인 화면의 설정 → 전체 기록 삭제에서 두 단계 확인을 마치면 최근 기록, 최고 기록, 누적 통계와 업적을 삭제합니다. 이 기능은 사용자 설정과 튜토리얼 완료 표시를 유지합니다. 진행 중인 판을 종료한 뒤 사용할 수 있습니다.

설정 초기화는 소리·진동·화면 설정을 기본값으로 되돌리는 기능이며 기록 삭제와 별개입니다. 남아 있는 설정·튜토리얼 완료 표시를 포함한 모든 로컬 데이터는 Android 설정에서 앱 데이터를 지우거나 앱을 삭제하여 제거할 수 있습니다. 웹 버전은 브라우저의 해당 사이트 데이터를 삭제하면 제거됩니다.

개발자는 이용자의 기기에 있는 기록을 원격으로 조회하거나 복구하는 기능을 제공하지 않습니다. 앱 삭제, 앱 데이터 초기화 또는 브라우저의 사이트 데이터 삭제로 없어진 기록은 개발자가 복구할 수 없습니다.

5. 데이터 보호와 기기 권한

로컬 데이터는 기기의 앱 저장 영역 또는 브라우저의 사이트 저장 영역에 보관하며, 운영체제와 브라우저가 제공하는 접근 제한을 사용합니다. 개발자가 보관하는 게임 데이터 서버나 클라우드 백업은 없습니다.

Android 앱은 웹 기반 화면 실행을 위한 인터넷 접근 권한과 효과 진동을 위한 진동 권한을 선언합니다. 카메라, 마이크, 위치, 연락처, 사진, 문자 및 통화기록에 접근하는 기능은 제공하지 않습니다.

6. 문의 처리와 이용자의 권리

이용자는 앱 설정의 삭제 기능으로 로컬 기록을 직접 삭제할 수 있으며, 데이터 처리에 관한 문의는 아래 이메일 주소로 보낼 수 있습니다. 계정을 만들지 않는 앱이므로 별도의 회원 탈퇴 절차는 없습니다.

이메일로 문의하면 이용자가 직접 제공한 이메일 주소와 문의 내용을 Google Gmail을 통해 수신하고 답변·문제 해결을 위해 이용합니다. 문의 자료는 답변과 처리가 끝난 후 삭제하되, 법령에 따른 보관 의무가 있는 경우에는 해당 범위와 기간에 따라 보관합니다. 문의 시 불필요한 개인정보나 실제 금융정보를 보내지 마세요.

7. 방침 변경

앱의 데이터 처리 방식이 변경되면 이 개인정보처리방침의 내용과 시행일을 갱신합니다. 중요한 변경은 적용 전에 앱 업데이트 안내 또는 개인정보처리방침 페이지를 통해 알립니다.

이 공개 페이지의 호스팅 안내

이 개인정보처리방침 웹페이지는 GitHub Pages에서 제공합니다. GitHub는 로그인 여부와 관계없이 페이지 방문자의 IP 주소를 보안 목적으로 기록하고 보관합니다. 자세한 처리 방식은 GitHub 개인정보처리방침을 확인하세요.

관망 스튜디오는 이 정책 페이지에 광고, 방문 분석 도구나 개인정보 입력 양식을 추가하지 않았습니다. 티커 앱은 이 페이지를 자동으로 불러오지 않으며, 위에 안내한 기기 내 게임 기록 처리 방식은 그대로 적용됩니다.
